# C++ Module 01 — Memory and References

C++98 exercises on object lifetime, pointers, references, file streams, and member-function pointers.

## In this repository

- `ex00`–`ex01` — Manage individual zombies and dynamically allocated arrays.
- `ex02`–`ex03` — Compare pointers and references through address printing and a shared weapon.
- `ex04` — Replace text in a file and write the result to a separate file.
- `ex05` — Dispatch Harl’s log messages through member-function pointers.

## Build and run

```sh
make -C ex04
make -C ex05
./ex05/Weapon
```

Run `./ex04/program filename search replacement` to generate `filename.replace`.
